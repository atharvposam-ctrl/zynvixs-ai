# Career workspace

The current update replaces generic note forms with dedicated profile, LinkedIn, interview, learning, email, application and project workflows, while reusing the existing local chat engine and SQLite data.

Read **[STUDIO_WORKFLOWS.md](STUDIO_WORKFLOWS.md)** for startup instructions, each page's actual behavior, model/mail/browser configuration, controlled test-mail setup, verification results and implementation limits.

Download the current [built application ZIP](https://github.com/atharvposam-ctrl/zynvixs-ai/raw/refs/heads/main/zynvixs-main.zip). Preserve your existing `data` and `models` folders. Run `Setup.bat`, then `Zynvixs.bat`.

AI workflows need a loaded llama.cpp model. Email needs configured IMAP/SMTP credentials. Browser assistance needs optional Playwright/Chromium. No unattended schedules or full-PC control are claimed. Do not bypass the unresolved antivirus warning.
